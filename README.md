# Mini Banking App

A Python-based mini banking application that supports multiple accounts, account creation, deposits, withdrawals, and transaction history.

## Features
- Create 5+ accounts (or more)
- New account creation with unique account numbers
- Deposit, Withdraw, Check Balance
- Transaction history per account
- Persistent storage (JSON)

## Requirements
- Python 3.8+
- Built-in packages: `json`, `os`

## Usage
```bash
python banking_app.py
